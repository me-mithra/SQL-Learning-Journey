# Day 02 - Combining Tables with SQL Joins

## 🎯 Objective

Understand how to combine data from multiple tables using SQL JOINs and learn how relationships between tables work


## 📚 Concepts Learned

- Primary Key
- Foreign Key
- INNER JOIN
- OUTER JOIN
- Table Aliases
- Joining More Than Two Tables



## 💻 Practice

Practiced combining data from multiple tables using different types of SQL JOINs. 
Learned how Primary Keys and Foreign Keys establish relationships between tables and used table aliases to write cleaner and more readable queries.
