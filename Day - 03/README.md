# Day 03 - SQL Aggregate Functions

## 🎯 Objective

Learn how to summarize and analyze data using SQL Aggregate Functions and understand how to group and filter aggregated results.



## 📚 Concepts Learned

- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- GROUP BY
- HAVING
- COUNT(DISTINCT column)



## 💻 Practice

Practiced SQL Aggregate Functions using the Retail Sales Dataset(https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset).
Learned how to calculate totals, averages, minimum and maximum values, count records, group data based on different categories, and filter grouped results using the HAVING clause.

## 📝 Reflection

Today, I learned how SQL Aggregate Functions help summarize large amounts of data into meaningful insights. 
Using `GROUP BY` allowed me to organize data into categories, while `HAVING` helped filter grouped results based on specific conditions.
These concepts showed me how SQL is used to generate reports and answer business-related questions from raw data.

Every dataset has a story. Aggregate Functions help uncover that story. This is my Day 03.
